# Project Instructions

## AI calls

- The project uses `PORTKEY_API_KEY` from the root `.env` file.
- Use OpenAI for AI calls.
- Use the `gpt-5.6-luna` model for AI calls.
- Never hard-code, print, commit, or expose the API key. Load it from the environment instead.

## Web apps and creatures

- When creating a Labubu or any other creature for a web app, implement it in HTML.
- All web apps should use a black-and-pink visual style unless the user gives a more specific direction.
